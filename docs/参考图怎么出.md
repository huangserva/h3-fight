# 参考图（定妆图）怎么出

H3 的 `MiniMaxH3ReferenceToVideo` 最多吃 9 张参考图。本 skill 的 `三参考图.json` 模板固定用三张：人物 `<Picture 1>`、场景 `<Picture 2>`、对手 `<Picture 3>`，还可以用 `--加参考图` 加到第 4–9 张（例如变身后的造型、第二个对手）。

用什么工具出图都行（Midjourney、Flux、SDXL、GPT 图像、Codex 内置出图……）。要紧的是图满足下面的要求。

## 要求

| 图 | 要求 | 为什么 |
|---|---|---|
| 人物 | 全身，**三分之四侧身的战斗姿势**，主角朝画面右边；纯色或简单背景；16:9 横图，宽至少 1600 像素 | 正面站姿会被照搬进打斗：人物在打斗中突然正对镜头、张开双臂（踩坑“定妆图的正面站姿被照搬进打斗”） |
| 对手 | 同上，朝画面左边 | 和片子里的站位一致，减少翻边 |
| 场景 | 不带人物；画出后面要用的道具（钟、柱子、桥）当前的样子；16:9 | 场景定义和参考图一致，道具状态才不会前后变 |
| 变身后 / 第二造型 | 每种造型一张，姿势要求同上 | 变身段挂前后两张；后面的段把变身后的图换到第 1 张 |

- **想要的颜色、光效画进图里。** 参考图压过文字：图里是金色气焰，提示词写绿色也常常出金色。
- 也可以出一张“正面 + 侧面 + 背面”的角色设定图代替单张。
- 每段都挂同一套图。只靠文字和首帧接人物，越往后越走样。
- 提示词里写一句 `His pose and facing direction always follow the action and his opponent, never the standing pose of the reference picture.`

## 出图提示词模板

人物：

```
A full-body character sheet of <外形描述>, in a dynamic three-quarter side fighting stance facing right,
<武器/拳架>, plain light-grey background, cinematic 3D animation style (或 2D Japanese anime style),
sharp details, 16:9 landscape, at least 1600 px wide. No text, no watermark.
```

场景：

```
An empty <场景描述> with no people, <道具和它们现在的状态>, <光线/天气>, cinematic wide shot,
16:9 landscape, at least 1600 px wide. No text, no watermark.
```

## 例：用 Codex 出图

我们自己是用 Codex CLI 的内置出图工具出的，三张并行，几分钟：

```bash
codex exec --skip-git-repo-check -C refs/ --sandbox workspace-write \
  "用你内置的图像生成工具画一张图，保存为当前目录下的 hero.png（16:9 横图，至少 1600 像素宽）：<上面的人物模板>"
```

坑：在 zsh 脚本里拼提示词时，**变量名用英文**。zsh 不认中文变量名，`共同="..."` 会被当成命令执行失败，`$共同` 变成空的，出图工具收不到姿势和画幅要求，出成竖图、直立侧面。
