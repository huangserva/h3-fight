# 一人破阵：参考原片 vs H3 快版成片

“特效大场面快剪”（SKILL.md 同名一节）的对照样例。

| 文件 | 内容 |
|---|---|
| `原片.mp4` | 参考原片，约 30 秒，Arvin AIGC 作品，经作者授权放在这里做对照 |
| `快版成片.mp4` | 用本 skill 复刻的快版，约 31 秒：H3 正片 3 段 + 补角度 3 段，`工具/混剪.py` 剪成，连续底音 + 重击叠音 |
| `长版/长版成片.mp4` | 先做长版的做法：H3 长版 6 段约 61 秒，一条连贯的故事，能单独看 |
| `长版/快版成片.mp4` | 从长版剪的快版，约 30 秒，她在打的镜头加速 1.4–1.6 倍、大特效 2–3 倍。**推荐看这条**：比补角度版连贯，主角一路在打 |
| `长版快剪.mp4` | 同一条长版的另一种剪法，29.3 秒：照参考片 0.4 秒一切，最新版和旧版（同一拍的另一个机位）来回切，82 段、白闪 4 处、连续底音 + 6 处重击 |
| `剪辑表_长版快剪.json` | 上面这条的剪辑表。`源` 里的 `长版素材/cbN_0000x_.mp4` 是 H3 出的长版各段（c = 最新版，a = 旧版），换成自己的素材路径即可 |

量速度（`工具/量速度.py`）：

| | 每 10 秒切镜 | 镜头中位长 | 光流 px/帧 |
|---|---|---|---|
| 原片 | 13.3 | 0.42 秒 | 4.13 |
| 快版成片（补角度） | 12.6 | 0.44 秒 | 5.51 |
| 长版/快版成片（留长） | 7.4 | 0.83 秒 | 6.41 |
| 长版快剪（0.4 秒一切） | 8.5（实际 82 刀，同色换机位量不出来） | 0.46 秒 | 6.20 |

根目录这条快版走的是补救做法（补角度素材）。`长版/` 里是 SKILL 推荐的做法：先做约 2 倍长、能单独看的长版，再从长版加速剪快版，过程和三轮的教训见 `长版/拍子覆盖表.md` 开头。
