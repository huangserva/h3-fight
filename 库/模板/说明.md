# 这里放你自己搭的工作流 / Put your own workflows here

照 `docs/工作流怎么搭.md` 在 ComfyUI 里搭好，用“导出（API）”存成：

- `三参考图.json`：有参考图（人物、场景、对手），`出片.py --参考图 …` 用它
- `无参考图.json`：只靠提示词

Build the workflow in ComfyUI as described in `docs/工作流怎么搭.md`, then use Export (API) and save it here as `三参考图.json` (with reference images) and `无参考图.json` (prompt only).
