# 这里放你自己搭的工作流 / Put your own workflows here

最省事：跑 `python3 工具/建模板.py`，它会在这里生成下面两个文件（已有的不动）。

想自己搭：照 `docs/工作流怎么搭.md` 在 ComfyUI 里搭好，用“导出（API）”存成：

- `三参考图.json`：有参考图（人物、场景、对手），`出片.py --参考图 …` 用它
- `无参考图.json`：只靠提示词

The quick way: run `python3 工具/建模板.py`, which writes both files here (existing files are left alone). To build them by hand instead, build the workflow in ComfyUI as described in `docs/工作流怎么搭.md`, then use Export (API) and save it here as `三参考图.json` (with reference images) and `无参考图.json` (prompt only).
